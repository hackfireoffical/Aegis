# Aegis

Realistic missiles and radar for Minecraft.

- Loader: NeoForge 1.21.1 (Java 21)
- Mod id: `aegis`

## Plan
1. Radar block that detects entities and missiles in range
2. Missile item and entity with realistic flight (boost, cruise, terminal phase)
3. Launcher block, targeting, radar screen UI
4. Sounds, particles, explosion effects

## Build
Built on GitHub Actions (see `.github/workflows/build.yml`). Download the jar from the Actions artifacts.
